# Instruções do Projeto (GEMINI.md)

Este arquivo contém a arquitetura, convenções e fluxos de trabalho compartilhados para o projeto de desenvolvimento de currículos.

## Visão Geral do Projeto

O objetivo deste projeto é criar currículos diretos, limpos e focados em resultados, otimizados tanto para recrutadores humanos quanto para Sistemas de Rastreamento de Candidatos (ATS).

## Arquitetura e Design (Estrutura do Currículo)

Todos os arquivos de currículo produzidos neste projeto devem seguir esta estrutura estratégica:

1. **Cabeçalho (Dados de Contato):** Nome completo, Cidade/Estado, Telefone, E-mail Profissional, LinkedIn e Portfólio (ex: GitHub). Sem documentos ou endereço completo.
2. **Objetivo Profissional:** Uma única linha indicando o cargo pretendido (ex: "Analista de Infraestrutura Cloud").
3. **Resumo Profissional:** Um "pitch" de 3 a 5 linhas destacando as principais competências e diferenciais.
4. **Experiência Profissional:** Ordem cronológica inversa. Foco em **resultados quantificáveis** e conquistas usando verbos de ação (ex: "Reduzi o tempo de deploy em 20%").
5. **Formação Acadêmica:** Nome do curso, instituição e status/data de conclusão.
6. **Competências (Hard & Soft Skills):** Lista direcionada de ferramentas, linguagens e habilidades comportamentais relevantes.
7. **Idiomas e Certificações:** Níveis de proficiência honestos e certificações oficiais (ex: AWS, Cisco).

## Convenções e Estilo

- **Formato:** Preferência por layouts limpos. Evite tabelas complexas, gráficos ou "barras de progresso" para habilidades (ex: 80% Inglês).
- **Tipo de Arquivo:** Exportar versões finais para PDF ou Word.
- **Extensão:** Máximo de 1 a 2 páginas (preferencialmente 1 página).
- **Otimização para ATS:** Use palavras-chave extraídas das descrições das vagas.
- **Exclusões:** Sem fotos, sem clichês ("proativo", "aprendizado rápido") e sem referências redundantes.

## Fluxos de Trabalho

- **Pesquisa:** Analisar descrições de vagas para identificar palavras-chave antes de redigir.
- **Implementação:** Elaborar o currículo seguindo as seções estruturadas.
- **Validação:** Verificar contra a lista de "Exclusões" e garantir que todos os resultados sejam quantificados sempre que possível.

## Ferramentas

- Markdown para redação e controle de versão.
- PDF/Word para distribuição.
